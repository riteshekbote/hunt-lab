- Q6: ✅ Not on always-rejected list

**Minimal proof**: `git log --all -p -- tests/unittests/plugins/test_bigquery_agent_analytics_plugin.py` or GitHub search `ya29. repo:google/adk-python` → extract token → attempt `curl -H "Authorization: Bearer <token>" https://bigquery.googleapis.com/bigquery/v2/projects/...` to demonstrate live validity.

**Impact**: Credential leakage enabling unauthorized access to the token owner's GCP resources (BigQuery, etc.).

**CVSS 3.1**: **7.5 (High)** — AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N (stored credential exposure in public repo)

**Reporting channel**: Google VRP via bughunters.google.com (ADK is a Google project; if token is a Google Cloud OAuth token, this is in scope).

**Caveat**: Must verify token is not already reported/rotated. If rotated and revoked → downgrade to HOLD then INVALID.
